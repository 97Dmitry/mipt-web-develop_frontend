# Лампочки — frontend интернет-магазина

Учебный проект по курсу веб-разработки (МФТИ). Пользовательская часть интернет-магазина светодиодных и других ламп: каталог, карточка товара, корзина, оформление заказа.

## Стек

- **Vite** + **React 19** + **TypeScript**
- **React Router DOM v6** — клиентский роутинг
- **CSS Modules** — изолированные стили компонентов
- Состояние корзины — **React Context + useReducer + localStorage**, без внешних state-менеджеров
- **ESLint** — статический анализ

Backend по условию задания не подключаем — все данные mock-овые. При этом форматы (`priceMinor` в копейках, `sessionId` как UUID, статусы заказа) совместимы с реальным backend в `~/mipt/web-develop`, чтобы при подключении заменить только содержимое `src/api/*`.

## Структура

```
src/
├── main.tsx, App.tsx          # точка входа и маршруты
├── types/domain.ts             # доменные типы (Product, Order, ...)
├── data/                       # mock-данные (5 категорий, 20 товаров)
├── api/                        # сервис-слой (сейчас mock, потом fetch)
├── context/                    # CartContext + useCart
├── pages/                      # 6 страниц
├── components/                 # ProductCard, фильтры, layout, ui-примитивы
├── utils/                      # format, validation, storage
└── styles/                     # global.css, reset.css
```

## Маршруты

| Путь                    | Страница                |
|-------------------------|-------------------------|
| `/`                     | Каталог с фильтрами     |
| `/products/:productId`  | Карточка товара         |
| `/cart`                 | Корзина                 |
| `/checkout`             | Оформление заказа       |
| `/orders/:orderId`      | Подтверждение заказа    |
| `*`                     | 404                     |

## Команды

```bash
npm run dev       # dev-сервер на http://localhost:5173
npm run build     # production-сборка (tsc + vite build)
npm run lint      # eslint
npm run preview   # запуск собранной версии
```

## Что не сделано (и почему)

- **Админ-панель** — вне ДЗ.
- **Авторизация** — вне ДЗ (клиентская часть гостевая).
- **Реальный backend** — по условию.
- **Тесты** — не требуются по ДЗ; функциональность проверяется ручным e2e-обходом.
